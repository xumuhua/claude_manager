# 境外虚拟信用卡订阅 ChatGPT 调研（2026-09-12）

> 调研：亦菲（manager）｜时点：2026-09-12
> 背景：哥哥问"想搞一个境外的虚拟信用卡来买 GPT 额度，该怎么做"

---

## 1. ⚠️ 行业现状：虚拟卡大地震（2025-2026）

曾经的顶流 **WildCard 已于 2025 年 7 月 12 日停服**（官方称"政策原因/不可抗力"），随后官网无法访问；同年 9 月以 9191.ai / WildAI 品牌回归，但不再发虚拟卡，只做代充。

**停服潮蔓延**：BinGoCard（2025-07）、OneKey Card（2025-01）、DuPay（2025-11）相继关停。

**根因**（多方整理）：境内对跨境支付/反洗钱监管收紧、上游卡组织（Visa/Mastercard）风控调整、合规成本过高导致商业模式不可持续。

**核心教训**：做虚拟卡=平台跑路风险真实存在。**任何平台都不要留大额余额**，随用随充；警惕假冒"退款客服"的诈骗。

## 2. 四条可行路径（按推荐度排序）

### ① 美区 Apple 礼品卡 + App Store 内购 —— 最稳（约 ¥145/月）

**适合**：ChatGPT Plus/Pro 个人订阅。**不适合**：API 额度充值。

#### 第一步：准备一个美区 Apple ID

两条路：
- **新注册美区 ID**（推荐，干净）：appleid.apple.com 注册新账号，国家/地区选**美国**，付款方式选 **"无"（None）**，地址填美国真实存在的地址（常用俄勒冈等免税州地址——还能省 App Store 消费州税），手机号可用国内号收验证码
- **把现有国区 ID 转美区**（不推荐主力号这么干）：改区要求余额清零、无未完成订阅，改完国区购买记录还在但后续麻烦

#### 第二步：Mac 上登录美区 App Store

> 关键点：**只登 App Store，不登 iCloud**——两个账号体系是分开的，各登各的互不干扰。

1. 打开 **App Store** 应用
2. 点左下角头像（或"商店"菜单 → 退出登录），**退出当前国区账号**
3. 用美区 Apple ID 登录 → 商店自动切到美区（界面变英文、价格变美元）
4. **千万别在"系统设置 → Apple ID"里登美区号**——那会把 iCloud 切走，照片/备忘录/钥匙串同步会乱。iCloud 保持国区号不动

iPhone/iPad 同理：设置 → 头像 → **媒体与购买项目** → 退出 → 登美区号（iCloud 不动）。

#### 第三步：充值礼品卡

1. 淘宝高评分店铺或支付宝"出境"频道买**美区**礼品卡（$25 ≈ ¥182，汇率约 7.2-7.25）
2. App Store 里点头像 → **兑换充值卡或代码** → 输入卡密，余额到账

#### 第四步：订阅 ChatGPT Plus

1. 美区 App Store 下载 ChatGPT App（注意 Mac 客户端内购支持不如 iOS 稳定，**主流做法在 iPhone/iPad 上完成内购**）
2. App 内"升级到 Plus" → 用余额支付 $20/月
3. 到期自动从余额扣款（记得余额留够）；订阅后 Web 端通用

**优点**：走 Apple 正规支付通道，完全不碰虚拟卡风险；月均约 ¥145，是正规渠道中成本最低。
**缺点**：只能在 iOS 设备上完成内购操作；不能充 OpenAI API 额度。

#### 常见坑

- 付款方式看不到"无"：先把地区改成美国再填地址，"无"才会出现；挂着订阅或有未结清余额时也不出现
- 礼品卡有区锁：美区卡只能充美区号，别买错区
- 登美区号不需要翻墙（商店切换直连即可），但 ChatGPT App 本身使用仍需科学上网

### ② 仍在运营的虚拟卡平台 —— 能充 API，但有门槛

**适合**：需要 OpenAI API 额度、或多种海外订阅的用户。

- 现存平台：**PokePay、VCard、WasabiCard** 等
- 充值方式：多数要求 **USDT**（需先有加密货币），全球付等少数仍支持支付宝但卡段老化
- 成本：开卡费+年费约 ¥1800 级别
- **订阅技巧**：账单地址填美国**免税州**（俄勒冈 Oregon / 特拉华 Delaware 等）免销售税
- **风险**：OpenAI 对部分卡段有风控，支付成功率有波动；平台本身有跑路风险（见 §1），不存大额余额

### ③ 第三方代充 —— 最省事（¥148-158/月）

- 支付宝付款，约 5 分钟完成，适合不想折腾
- **缺点**：需把账号密码交给第三方，选信誉好的商家；本质是把信任成本转移到人身上

### ④ 美国实体银行卡 —— 一劳永逸的长期方案

- **华美银行（East West Bank）**、**国泰银行（Cathay Bank）**：支持中国护照远程开户
- 一次性开户成本较高，但之后 OpenAI、各类海外订阅全通，无虚拟卡的跑路/风控问题
- 适合长期有持续海外支付需求的用户

## 3. 决策建议

| 需求 | 推荐路径 | 月成本 |
|---|---|---|
| GPT Plus/Pro 个人订阅 | ① 美区 Apple 礼品卡 | ≈¥145 |
| OpenAI API 额度 | ② 虚拟卡（USDT 门槛）或 ④ 实体银行卡 | 视用量 |
| 图省事、短期用 | ③ 代充 | ¥148-158 |
| 长期稳定海外支付 | ④ 美国实体银行卡 | 一次性开户成本 |

**体系备注**：咱们 AWS gpt 机的 codex 已走 OAuth 登录态，gpt 侧使用已被覆盖；本调研主要解决哥哥个人订阅或为中转站（9536 LiteLLM）增设 OpenAI 直连通道的支付问题。
