## 2. G5/G6 实测细节

- **G5**：B1 历史频率（同 VS 全局五分位 × H 无条件率，拟合窗估计），valid 三步合并逐对象 ECE（10 等频 bin）。三对象 ECE ∈ [0.068, 0.091]，全部 ≤0.10，最大者为 bottoming_H10 的 0.0907。
- **G6**：
  - 选参（仅 train，87,511 event 锚等距子样本）：等距带族最优 = [close−8.75VS, close]（fit 覆盖 80.2%，带宽中位 0.212×close）；历史频率经验带 = [q5≈−0.009, q95≈0.154]（fit 覆盖 80.0%，带宽 0.163）。
  - 样本外（valid 三年逐年）：等距带覆盖 80.3%/76.2%/81.8%，带宽 0.165/0.216/0.178；经验带覆盖 86.6%/77.1%/86.4%，带宽恒 0.163。
  - 带宽比 = 0.163 / median(0.165,0.216,0.178) = **0.917** ≤ 1.2 → 过。
  - 解读：**过门仅说明"等距带不劣于最优基线 20% 以上"（P0-05 §7.3 原文语义），即区间方向未被证伪、可继续探索**；但两族带本身质量平庸——2018 年等距带覆盖掉到 76.2%（波动结构漂移），校准均不完美。G6 过 ≠ 区间好用，只 ≠ 区间无价值。

**核心发现（如实公开，含差的）**：朴素基线的排序/区分能力≈无——ROC-AUC 多数 <0.5，Brier 相对当年无条件率改善在 −4%~+2% 之间震荡。基线提供的价值是**校准尚可的频率锚**（ECE≤0.09），不是排序信号。这正是预注册该回答的问题：三对象"以朴素方式可预测性很低"，复杂模型的增量门槛（P1-11 预注册 Brier≥2pp 且 CI 不含 0）将面对一个"无条件率就几乎打平"的基线——**增量空间存在但必须靠真实特征**，P0-07 不过复杂模型闸（本包不启动 P1，仅解锁）。

## 4. 最差组与失败分析（valid，B1）

- 高波动组（vs_q=4，2017）：touch ECE 0.175、rej|touch ECE 0.153——历史频率在波动结构切换年（2017 蓝筹低波年 vs 拟合窗含 2015 极端）系统性高估触达。**校准漂移集中在高 VS 组×风格切换年**。
- 行业最差：2018 煤炭/非银/钢铁 touch ECE≈0.13–0.14；bottoming 2018 综合 ECE 0.156。
- 区间：2018 等距带覆盖 76.2%（目标 80%）——熊市单边年中 VS 缩放量纲低估极端跌幅。
- 行业频率基线（B5）几乎不提供增量（Brier 与 B1 打平或更差），且行业 NaN 率 37.9%（sw_member 覆盖缺口，主要是 2014 前历史）——已如实登记，不影响 B1 判定。
- Brier 改善为负的年份（2017/2018）机制：走步拟合窗的事件率高于当年实际（2015 高频年污染先验），历史频率基线在 regime 切换时滞后。这是朴素基线的固有局限，不是泄漏。

- test 段（2020/2021）数字仅诊断对照（见 metrics_summary.csv segment=test_diag），未参与 G5/G6 判定、未参与任何选择。诊断侧 B1 ECE 反而更低（0.007–0.045），不改变任何结论。
- shadow（2022+）未读未碰。
