# D4 v3｜P1-08 全市场状态研究触门裁决书

**裁决编号：** D4V3-P1-08-R1  
**裁决结论：** **维持停机，启动 P1-08A 限定整改；M2 保留为研究 champion，但不得直接进入生产状态发布链。**

M2 已证明相对历史频率存在样本外概率增量，但尚未证明其概率在关键状态下可被安全使用。G7 的度量设计确有缺陷，尤其是 G7b；然而 2017 年结果也揭示了真实的方向识别、校准和输出坍缩问题，不能仅靠修改门槛解除停机。

# 二、逐条裁决

## 1. G7a：ECE≤0.10 是否过严？

### 裁决

**不能直接认定 0.10 过严，也不能因为 M2 的 ECE=0.152 优于 M0=0.214，就把门放宽到 0.15 或 0.16。**

“多分类比二分类更难”不足以成为放宽依据。ECE 的数值高度依赖：

- top-label ECE、classwise ECE 或 marginal ECE；
- 分箱方法和箱数；
- 样本量；
- 类别占比；
- 是否按预测置信度或逐类概率计算。

因此，P0-07 二分类 G5 的 0.10 不能机械平移到 P1-08，但 P1-08 也不能在看到 0.152 后反向制定阈值。

### 对本次结果的认定

M2 的 ECE 相对 M0 改善约 **29.0%**，说明模型学习到有效信息；但绝对 ECE=0.152 仍意味着概率不可直接当作可靠置信度使用。

故分开裁决：

- **预测能力：通过。**
- **校准可用性：不通过。**
- **模型资格：保留为待校准 champion。**
- **生产资格：不通过。**

### G7a 新定义

P1-08A 不再以单一 pooled ECE 判生死，改为：

1. 预注册一种主 ECE：建议 **adaptive-bin top-label ECE**；
2. 同时报 classwise ECE、最大 classwise ECE、Brier、log loss；
3. 所有指标给出按年份 block bootstrap 置信区间；
4. 同时设置绝对门和相对基线门。

建议的预注册门：

- 主 ECE 点估计 `≤0.12`；
- 主 ECE 的 95% bootstrap 上界 `≤0.15`；
- 相对 M0 的 ECE 改善 `≥20%`；
- 最大 classwise ECE `≤0.20`；
- Brier 继续严格优于 M0，且改善不能主要由一个年份贡献。

这些阈值仅可用于**新冻结评估集**。不得拿 2017–2019 原样重跑后宣称确认性通过。

## 2. G7b：是否改看概率软转移矩阵？

### 裁决

**是。G7b 的主门必须改为概率软转移矩阵。**

当前 0.983 主要衡量的是 argmax 决策面的不稳定性，而不是完整概率分布的漂移。四分类中，概率从：

```text
[0.26, 0.25, 0.25, 0.24]
```

微调为：

```text
[0.25, 0.26, 0.25, 0.24]
```

即可令硬状态完全翻转，尽管概率本身几乎未变。因此，硬 argmax 转移矩阵不适合作为模型漂移主门。

### 软转移定义

对相邻日期预测概率 \(p_t\)，定义：

\[
\widetilde T_{ij}
=
\frac{\sum_t p_t(i)\,p_{t+1}(j)}
{\sum_t p_t(i)}
\]

若将来使用序列模型并能输出联合后验，则优先使用：

\[
\widetilde T_{ij}
=
\frac{\sum_t P(S_t=i,S_{t+1}=j\mid \mathcal F_t)}
{\sum_t P(S_t=i\mid \mathcal F_t)}
\]

需明确：对 M2 使用概率外积是一种**软诊断近似**，不是对潜在状态联合转移的严格估计。

### 新的 G7b 指标组

主门应同时检查：

- 软转移矩阵变化；
- 概率状态占用率变化；
- 预测熵变化；
- 每类平均预测概率与实际频率偏差；
- Jensen–Shannon divergence 或归一化矩阵距离；
- 相对训练期滚动分布的置信区间。

### 硬 argmax 指标如何保留

硬转移矩阵不应删除，而应降级为**输出坍缩报警器**。

2017 年 244 日中 243 日为同一 argmax，仍是严重问题。即使软转移正常，也说明：

- 下游若消费硬状态，将全年退化为常量；
- argmax 状态不具备业务辨识度；
- 模型的概率排序与真实状态方向严重错位。

建议新增独立门 G7d：

- 任一年度单一 argmax 状态占比 `>90%`：黄色报警；
- `>97.5%`：红线；
- 除非实际同一状态占比也达到相近水平，且 Brier、log loss、校准均通过。

因此，**撤销 0.983 的原主门含义，不等于赦免 2017 坍缩。**

## 3. G7c：最差组 ECE=0.373 是否构成灾难？

### 裁决

**是，当前应按灾难处理。**

但问题不是“某个最差组 ECE 超过人为设定的 0.20”这么简单，而是该组同时满足：

- 具有完整年度规模，不是极小样本噪声；
- 概率方向发生系统性错误；
- 实际 bull_lowvol 占 72.5%，模型却高配 bear_lowvol；
- argmax 几乎全年坍缩；
- 误差具有连续时间聚集性，而不是零散随机误差。

这代表模型在一个经济上合理且可能复现的环境中失去可靠性。2017 不是数据故障，不能豁免。

### G7c 新定义

最差组门必须避免“小样本组天然成为最差组”和事后任意切组。整改为：

- 分组维度、边界必须预注册；
- 每组需满足最低有效样本数，例如 `n≥100` 或不少于一个完整评估窗；
- 年份与 `vol_q` 分别报告，并补充二者交叉组；不能只报最坏交叉切片；
- 使用 block bootstrap，保留时间相关性；
- 同时报组内 Brier、log loss、ECE、偏置方向和相对 M0 增量。

建议判定规则：

- **红线灾难**：组内 Brier/log loss 显著劣于 M0，或出现系统性反向预测并伴随硬输出坍缩；
- **校准失败**：ECE 上界越门，但 proper score 仍优于 M0；
- **样本不足**：不作通过结论，标记为 unsupported，而不是自动判灾难或自动豁免。

2017 当前符合第一类，而不只是一般校准失败。

# 三、2017 问题应在模型层还是状态定义层解决？

## 主裁决：先模型层，后标签审计

不能因为模型预测失败就重定义状态。否则等同于用验证集修改目标，破坏确认性评估。

2017 的 bull_lowvol 单峰年并非语义矛盾：持续上涨与低波动可以同时存在。因此，“训练期未出现如此极端的年度占比”本身不足以证明状态定义错误。

### 模型层必须整改

四个联合状态建议由单一四分类 softmax 改为可审计的层次或因子化结构：

\[
P(D,V)=P(D)\times P(V\mid D)
\]

至少分别输出：

- \(P(direction=up)\)
- \(P(volatility=high)\)
- 必要时的方向—波动交互修正
- 最终四状态联合概率

优点是即使某个联合状态在训练期稀少，模型仍可从方向和波动的边际样本中学习，不必完全依赖历史联合频率。

同时加入：

- expanding window champion；
- 固定长度 rolling window challenger；
- 指数衰减加权 challenger；
- 正则化时间趋势及少量预注册非线性；
- 多分类温度缩放或向量缩放；
- OOD/支持度检测；
- 低支持度时的概率收缩与降级策略。

### 状态定义只在以下证据出现时修改

- 标签阈值对轻微参数变化极度敏感；
- 标签存在明显前视、全样本分位数或修订数据泄漏；
- 方向与波动定义在经济语义上互相冲突；
- 四状态对下游决策没有增量，而连续概率有；
- 相邻状态边界产生大规模机械翻转。

若需修改标签，必须升版为新的状态 taxonomy，并使用新的未触碰评估期；不得把它称为 P1-08 原规格的通过。

另需修正文档口径：当前“四状态”实际只对应**方向×波动**。流动性和广度若是输入特征，不应写成四维状态；若确为状态轴，则四状态数量不成立。

# 四、P1-08A 修改包规格

## A. 目标与范围

P1-08A 只解决四件事：

1. 修复联合状态在历史稀疏组合下的外推；
2. 建立可比较、带不确定性的多分类校准门；
3. 用软转移衡量概率稳定性；
4. 在 OOD/regime shift 下显式降级，不输出虚假确定性。

禁止事项：

- 删除 2017；
- 根据 2017–2019 结果反复挑特征或阈值；
- 仅把 ECE 门放宽到刚好通过；
- 用 HMM 复杂度掩盖 M2 的问题；
- 只报告 pooled 指标。

## B. 数据与评估协议

采用双轨报告：

### 轨道一：历史诊断

2017–2019 保留为“已观察整改集”，用于定位失败、展示修复效果，但结果标注为：

> exploratory / contaminated for model selection

不得作为 P1-08A 最终确认性验收依据。

### 轨道二：确认性评估

必须选择未参与本轮设计的后续连续时间窗，冻结：

- 标签；
- 特征；
- 校准器；
- 分箱方法；
- 分组方法；
- 阈值；
- champion 选择规则。

若暂时没有真正未触碰的数据，则 P1-08A 只能获得：

> conditional research pass / shadow only

不能获得生产通过。

## C. 模型候选

必须至少比较：

- **M0**：仅用当时可得数据计算的历史频率；
- **M2-E**：原 expanding logistic；
- **M2-F**：方向—波动因子化 logistic；
- **M2-R**：预注册窗口长度的 rolling logistic；
- **M2-D**：指数衰减加权 logistic；
- **M3**：原 HMM，仅作 challenger，不追加调参特权。

候选数量、超参数网格和选择规则必须预先冻结。主模型仍应优先选择可解释、稳定、参数较少者。

## D. 校准方案

校准训练必须嵌套在当时训练窗内部，不能使用对应验证年。

允许比较：

- temperature scaling；
- vector scaling；
- 带强正则的 multinomial calibration。

不建议在当前样本规模下优先使用高自由度逐类 isotonic，以免过拟合。

每个走步年份只允许用此前数据拟合校准器。

## E. 新版验收门

| 门 | 指标 | 裁决条件 |
|---|---|---|
| G7-1 预测增量 | Brier 主指标；log loss 佐证 | 主模型严格优于 M0；改善不能仅来自单一年份 |
| G7-2 总体校准 | 预注册 adaptive top-label ECE | 点估计≤0.12、95%上界≤0.15、相对 M0 改善≥20% |
| G7-3 类别校准 | classwise ECE | 最大值≤0.20；各类同时报告偏差方向 |
| G7-4 软稳定性 | 软转移 JS divergence/归一化距离 | 阈值由训练期滚动伪样本分布预注册，不再沿用硬矩阵 0.25 |
| G7-5 最差组 | Brier、log loss、ECE、相对 M0 | 不得出现支持充分组显著劣于 M0或系统性反向预测 |
| G7-6 坍缩 | 年度 argmax 占比、熵、有效状态数 | 单态>90%报警，>97.5%红线；需结合真实占比判定 |
| G7-7 OOD | 支持度/距离指标 | OOD 时必须触发收缩、降级或不发布 |
| G7-8 下游安全 | soft probability vs hard state | 默认只发布概率；硬状态不得作为唯一仓位开关 |

软转移阈值不应再主观指定为 0.25。应在训练期构造多个历史伪走步窗，得到稳定性指标的经验分布，再冻结例如 95% 或 99% 分位红线。

## F. OOD 与降级机制

每个交易日新增：

```yaml
market_state_probs:
  bull_lowvol: 0.00
  bull_highvol: 0.00
  bear_lowvol: 0.00
  bear_highvol: 0.00

direction_up_prob: 0.00
high_vol_prob: 0.00
predictive_entropy: 0.00
effective_state_count: 0.00
support_score: 0.00
ood_flag: false
calibration_status: pass|warning|fail
publication_status: normal|shrunk|baseline|abstain
```

降级顺序：

1. 正常发布校准后的 M2 概率；
2. OOD 黄色：向当时可得的历史频率收缩；
3. OOD 红色或连续校准越界：降级至 M0；
4. 数据质量异常：停止发布。

不得用 OOD 标志把坏预测从评估集中删掉；降级后的最终输出也必须纳入评分。

# 五、最终放行规则

P1-08A 完成后只允许三种结论：

1. **Production pass**  
   未触碰确认窗通过全部硬门，可以向下游发布校准概率。

2. **Shadow pass**  
   Brier 有增量，但校准、最差组或 OOD 降级尚未确认；仅影子运行，不驱动仓位。

3. **Research fail**  
   关键年份或支持充分组持续劣于 M0，或系统性方向误判不能消除；退回特征/标签审计。

就当前证据，P1-08 应归为：

> **Shadow pass：预测增量成立；生产概率可靠性不成立。**
