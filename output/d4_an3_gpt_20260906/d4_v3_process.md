## 2. 资料审阅路径与观察记录

### 2.1 第一遍：结构扫描

先统计文件并扫描标题、表格字段、时间口径、来源段和“下一日验证”段，目标是回答“最终产品要让用户看到什么”，而非“报告用了什么策略”。

共同输出槽位归纳为：

1. 截至时点与正式收盘/盘前的口径边界；
2. 市场仪表盘（指数、量能、广度、风格）；
3. 当期核心矛盾或事件；
4. 行业/主题横截面分化；
5. 跨市场输入；
6. 下一观察窗的正反验证；
7. 来源、数据口径与免责声明。

这直接影响 P0-04 的输出 schema，但没有决定任何预测特征。

### 2.2 第二遍：失败模式扫描

围绕时间、因果、粒度和可验证性审阅，得到四类系统性风险：

- 盘前、盘中、正式收盘若混用，会产生不可回放结论；
- 新闻与价格共现容易被写成单一因果；
- “科技强/风险偏好回归”等单标签会压掉广度、波动和流动性分化；
- “压力/突破/底部”若不先定义期限和路径条件，下一日无法客观验收。

因此顶层架构选择点时数据、三条并行证据流、多维概率状态和价格事件定义。

### 2.3 第三遍：将输出需求与方法脱钩

保留的是报告槽位与可读性；推倒的是报告本体可能使用的任何动量框架、阈值、主题标签和归因方法。最终形成“结构化结果是事实源，Markdown 只是渲染”的原则，防止文案反向主导模型。

## 3. 外部查证路径

外部查证不是寻找一篇论文替系统背书，而是分问题寻找边界：

### 3.1 市场状态

查证方向：非平稳时间序列、状态切换、变点检测、概率状态而非固定牛熊标签。Hamilton (1989) 支持状态转移建模，但不证明某组状态名称适合 A 股。因此只采纳“状态是隐变量且须以概率表达”的方法启发，具体状态由样本外检验决定。

### 3.2 事件

查证方向：经典事件研究的估计窗/事件窗、异常收益、预趋势、重叠事件和安慰剂；MacKinlay (1997) 是方法总览。由此确定必须把发布时间与首次可得时间分开，并把事实、意外度、暴露和反应拆开。

### 3.3 支撑/压力与技术形态

查证方向：技术形态是否可统计识别、价格聚类/订单聚集能否产生局部区域反应。Lo、Mamaysky 与 Wang (2000) 说明形态必须经统计检验；Osler (2003) 提供订单在特定价格聚集可能影响动态的微观证据。两者都不足以证明某条画线规则普适，所以最终只主张“候选区域 + 条件概率 + 样本外证伪”。

### 3.4 时间到事件、删失与概率评价

查证方向：触达、突破、沉底均是路径和期限问题；Cox 风险模型为时间到事件及删失提供基础。概率输出采用 proper scoring rules（Gneiting & Raftery）评估，并检查可靠性/校准；复杂模型须额外校准。区间预测关注覆盖与宽度，不只看点误差。

### 3.5 回测过拟合

查证方向：大量候选规则、阈值和模型挑选会制造赢家。由此加入预注册、冻结测试集、朴素基线、多重检验控制、走步回测和 champion/challenger。

### 3.6 官方规则核验路径

实际开发阶段必须从交易所/官方文档核验涨跌幅、交易日、停牌、除权、指数成分与板块制度，并版本化；不能凭通用记忆写死。当前顶层文档只把“显式处理这些制度”设为硬约束，不预设可能随时间变化的具体百分比。

主要公开依据及用途：

| 来源 | 采用内容 | 未作出的过度推论 |
|---|---|---|
| Hamilton 1989 | 状态切换/概率状态的理论起点 | 不认定固定状态数或标签 |
| MacKinlay 1997 | 事件窗、异常收益及研究设计 | 不把相关性升级为唯一因果 |
| Lo et al. 2000 | 图形规则需客观识别和统计检验 | 不采纳任何现成形态为真理 |
| Osler 2003 | 订单聚集可支持价格“区域”机制 | 不直接外推至所有 A 股/期限 |
| Cox 1972 | 时间到事件和删失 | 不预设比例风险一定成立 |
| Gneiting & Raftery 2007 | proper scoring rules | 不以单一指标代替全套评估 |
| Guo et al. 2017 | 现代模型概率可能失校准 | 不限定只能用温度缩放 |
| Bailey et al. 2014 | 回测多重尝试/过拟合风险 | 不把统计显著等同可交易性 |

链接与完整书目信息见策略文档第 7 节。

## 4. 问题重构过程

初始目标看似是串联链：“市场与事件 → 行业 → 个股价位”。审阅后将其重构为四个可分别失败的问题：

1. 截至 `t`，市场处于哪些状态，各自概率多少？
2. 哪些宏观/行业事实首次变得可知，其意外度和暴露如何？
3. 行业横截面是否显示扩散、拥挤、风险或相对强度，其状态概率如何？
4. 在上述条件下，个股未来是否触达某带、触达后拒绝或有效越过、是否形成已确认底部？

关键推导记录：

- 若事件与行业是严格串联，事件缺失会阻断所有预测，且易制造叙事因果；故改为并行流、晚融合。
- 若直接回归未来高/低点，模型混淆“是否可达”和“触达后反应”；故拆成候选生成、触达风险、条件结果。
- 若突破等于盘中越线，假突破无法定义；故加入确认窗和失败路径。
- 若沉底等于未来最低价，任何最低点都会被事后叫底；故加入随后稳定/修复，并处理右删失。
- 若状态只给标签，不确定性在报告中消失；故强制概率向量和过渡态。

## 5. 备选方案、取舍与否决理由

| 方案 | 表面优点 | 否决/暂缓理由 | 保留部分 |
|---|---|---|---|
| 单向宏观→行业→个股链 | 叙事清楚 | 同期反馈和领先关系被掩盖，易伪因果 | 报告可按此阅读顺序，不作为计算拓扑 |
| LLM 端到端读新闻报价位 | 开发快、语言自然 | 数值不可复现、易幻觉、无法校准 | 受约束事件抽取与摘要 |
| 固定阈值规则状态机 | 易解释 | 跨波动/板块不可迁移，边界突跳 | 作为 champion 基线 |
| 单一牛/熊标签 | 简洁 | 无法表达涨而窄、波动高、过渡态 | 多维状态的摘要标题 |
| 一开始上深度序列模型 | 可能拟合非线性 | 标签与数据未稳定前会掩盖错误 | P1 challenger，须过基线门 |
| 直接预测一个压力/底价点 | UI 简单 | 虚假精度，覆盖与失败不可表达 | 区间中心可用于排序但不可单独发布 |
| 未来最高/最低即压力/底 | 标签易算 | 没有触达反应与确认语义，纯事后 | 极值作为路径标签的组成部分 |
| 成交放大是突破硬条件 | 直观 | 不同证券/状态下尺度不同 | 作为可检验特征，不作永真规则 |
| 把历史高点全部当压力 | 候选丰富 | 多重检验和密集重复，命中可偶然 | 经聚类、距离与样本支持筛选候选 |
| 新闻情绪分数直接代表行业状态 | 覆盖快 | 语言情绪不等于市场定价，中文财经域漂移 | 与价格状态分列后做增量测试 |
| 只用准确率/AUC | 常见 | 类别不平衡且不评价概率真实性 | PR-AUC 辅助，proper score+校准为主 |
| 随机 K 折交叉验证 | 样本利用率高 | 时间泄漏和制度跨期污染 | 时间滚动、隔离/必要时 embargo |
| 用最新修订宏观数据回测 | 数据整洁 | 当时不可得，夸大事件模型 | 保存 vintages；缺失则缩小事件范围 |
| 报告人工二次改数字 | 灵活 | 失去单一事实源与可复现性 | 人工可改措辞但需 lint/审计，不能改数值 |

## 6. 已确立主张的证伪条件

### 6.1 架构主张

- **三流晚融合**：若在冻结留出期，联合模型对概率分数、区间或决策价值无稳定增量，则删除无效流；架构不以复杂为目标。
- **点时底座**：若随机历史快照不可重现，任何模型成绩作废。
- **状态概率**：若校准后不优于分组历史频率或状态无法区分未来分布，退回事实仪表盘。
- **结构化结果先于报告**：若报告数值不能逐项由 schema 生成，停止发布。

### 6.2 价位主张

- **压力区域**：匹配价格距离、波动和趋势后，候选带触达后的条件受阻率若与随机带无差异，则不存在可发布增量。
- **有效突破**：确认规则若不降低假突破或其延迟消灭后续信息价值，则只报告穿越，不报告有效突破预测。
- **沉底联合事件**：若稳定/修复定义在合理阈值扰动下不稳，或条件区间覆盖不达标，停止“沉底价”命名，改报未来下行分位数。
- **价格区间**：若为达覆盖率必须给出过宽区间，应明确“无信息”并不发布，不用高覆盖粉饰无用性。

### 6.3 事件与行业主张

- 安慰剂日期/伪事件产生相同效应，否决事件增量。
- 事件前趋势已解释全部反应，改记“市场已预期”。
- 重叠事件剔除后效应消失，不做独立归因。
- 行业结论由一两个权重股完全驱动，降级为个股集中现象。
- 更换合理分类体系后方向频繁翻转，行业状态标高不确定或撤销。

### 6.4 上线主张

- 连续两个监控窗概率校准越红线：重新校准或回滚基线。
- 数据缺失、时区/复权异常触发红线：阻断数值发布，仅给事实缺失提示。
- 实时表现显著弱于回测且无法解释：冻结模型，审计泄漏、漂移和执行约束。

## 8. 未决问题与执行侧必须回答的研究问题

1. 哪些期限既匹配报告用途又有足够事件样本？
2. 价格带宽采用 ATR、实现波动、成交密度带宽还是组合，哪种跨板块最稳？
3. 触达、离带、回撤、保持与修复阈值的稳定区间在哪里？
4. 涨跌停导致的不可观测供需如何标记：竞争事件、删失还是独立状态？
5. 行业分类和历史成分能否取得可靠点时版本？
6. 哪些宏观事件有历史预期数据；没有意外度时是否只报告事实？
7. 事件流对价位预测是否有留出期增量，还是只改善解释？
8. 区间达到目标覆盖率后宽度是否仍有业务价值？
9. 校准应全局、分状态还是分行业；小样本如何收缩？
10. 影子运行需覆盖多少不同市场状态才能做上线裁决？

这些问题已拆进路线图，不允许执行侧用直觉一次性决定。

## 9. 研究完成度与诚实边界

本阶段完成的是顶层可检验架构、对象定义、接口约束和施工路线，不是声称模型已在 A 股上验证有效。文献只能证明所用统计问题是合理的，不能证明 D4 v3 有预测优势。是否有效，要由 P0 标签/基线和 P1 严格样本外实验裁决。若最终只有事实跟踪可靠，而三类价位均不优于基线，合格结论就是缩小系统范围，而不是继续堆模型。
