# D4-ANALYZE.3 顶层策略：从市场状态到个股价格事件

> 版本：v1.0（2026-09-05）  
> 定位：执行侧施工总纲，不构成投资建议。本文从零定义系统，不沿用既有 D4 正典或 ANALYZE.1/2。

## 0. 决策摘要

D4 v3 应是一个**带时间戳、可回放、概率化、可证伪的市场研究系统**，而不是自动生成市场故事的写作系统。它在统一的“截至时点”上并行处理三条证据流：全市场状态、宏观/行业事件、行业横截面状态；随后把这些信息作为条件变量，预测个股未来价格事件。

系统不声称找到唯一因果。它输出：数据截至何时、当前状态的概率、事件证据强弱、行业状态、个股价格带、预测期限、发生概率、区间、失效条件及数据谱系。没有这些字段，就没有合格预测。

最重要的定义变化是：

- **压力位**不是图上的一条线，而是未来给定时窗内，上行首次触达某一价格带后出现受阻事件的条件概率显著升高的区域。
- **突破位**不是盘中越过某个数，而是越过候选压力带后，按预先规定的价格、成交与保持条件获得确认的价格带；它预测的是“有效突破事件”。
- **沉底价**不是最低价点估计，而是未来给定时窗内“下行极值 + 随后稳定/修复”联合事件中极值价格的条件分布。

三者均须用复权规则明确的**价格区间**表达，同时提供期限、概率、置信/预测区间、样本支持度和失效条件。

## 1. 系统定位与边界

### 1.1 做什么

1. 建立截至时点 `as_of` 可回放的全市场状态：趋势、波动、流动性、广度、相关性/拥挤度、风险偏好与跨市场压力。
2. 识别宏观和行业级事件，将“事实发生”“市场意外程度”“暴露映射”“价格反应”分开记录。
3. 估计行业情绪/状态的概率分布，而非只给强弱标签。
4. 在市场、事件、行业和个股自身状态条件下，预测压力、有效突破、沉底三个价格事件。
5. 生成机器可读结果和人类可读报告，并能逐条追溯至原始数据、模型版本和评估结果。

### 1.2 不做什么，以及为什么

- 不输出无期限的“看多/看空”。没有时窗的预测不可验证。
- 不把相关新闻与涨跌同时出现写成已证实因果。观察数据通常只能支持归因假设和增量解释。
- 不把个股新闻纳入“核心事件”发现主链；个股事件只作为个股层风险/公司行为控制项，防止把停牌、除权、财报等误归因给行业。
- 不给单一精确价点、确定性承诺或自动交易指令。市场价格是连续随机过程，点值制造虚假精度。
- 不用大模型直接生成数值价位。大模型可做受约束的信息抽取、去重和证据摘要，数值预测必须来自可回放数据与可评估算法。
- 不以回测期内最终修订数据替代当时可得数据；这会造成前视偏差。
- 第一阶段不追求高频盘口预测。报告形态是日内/收盘研究，先在日频或固定快照频率上建立可信基线。

### 1.3 目标用户与输出节奏

- 目标用户：研究员、风控人员、报告生成器及下游策略研究，不直接面向自动下单。
- 基准节奏：盘前快照、盘中可选快照、正式收盘版；不同快照绝不可混称同一口径。
- 基准预测窗：`1/3/5/10/20` 个交易日；可由任务研究后裁剪，但发布时必须显式给出。

## 2. 从零构建的架构主张

### 2.1 总体结构：三条并行证据流，条件化汇合

```text
时间点一致的数据快照
  ├─ 市场证据流：价格/成交/广度/波动/相关性/资金代理 ─┐
  ├─ 事件证据流：官方事实→意外度→行业暴露→反应窗口 ─┼─ 状态融合
  └─ 行业证据流：相对收益/广度/量价/扩散/拥挤度 ─────┘
                                                        ↓
                                         个股条件价格事件分布
                                                        ↓
                                  校准、反证、机器结果、人类报告
```

拒绝“宏观事件 → 行业情绪 → 个股价位”的硬编码单向链。真实市场中，状态会影响事件冲击，行业价格也会先于叙事反应；三流并行可减少故事倒推动机。

### 2.2 分层职责与层间契约

#### L0 数据与时点层

职责：接入行情、指数成分、公司行为、交易日历、宏观公布、政策/行业事件和来源文本；保存原始快照。

出站契约：`instrument_id, event_time, available_time, ingest_time, source_id, value, unit, adjustment, revision_id, quality_flag`。其中 `available_time` 决定回测能否使用。

证伪：若按 `available_time` 重放仍出现未来数据、复权跳变被当收益、来源间口径无法对账，则本层设计失败。

#### L1 规范化与质量层

职责：证券主数据映射、交易日对齐、复权、停牌/涨跌停/上市天数标记、缺失与异常处理、来源层级和重复事件合并。

出站契约：不可变快照 ID、质量报告、字段字典、可用域掩码。任何插补必须保留原始缺失标记。

证伪：在金样本上公司行为调整错误、交易时区错位或静默插补率超过预设门槛，则阻断下游。

#### L2 特征与证据层

职责：只产生截至 `as_of` 可计算的点时特征；市场、事件、行业、个股特征分命名空间管理。

建议特征族：

- 市场：多尺度收益、已实现波动、上涨家数比例、创新高/低、等权与市值权重差、成交额分位数、横截面离散度、平均相关性、涨跌停/停牌占比。
- 事件：事件类型、主体、发布时间、首次可得时间、来源等级、意外度、方向不确定性、作用期限、行业暴露权重。
- 行业：相对基准收益、行业广度、成交扩散、波动、领涨集中度、成分内相关性、跨市场对应资产表现。
- 个股：相对行业收益、波动/跳跃、成交、缺口、历史触达反应、流动性、涨跌停距离、公司行为控制。

证伪：随机抽取特征无法从原始快照独立复算，或特征在真实发布前改善结果，则特征库不合格。

#### L3 状态推断层

职责：输出市场和行业的**状态概率向量**，允许“不确定/过渡态”，不强制唯一标签。

推荐先用透明基线（规则分箱、逻辑/多项模型、隐马尔可夫或变点模型），再比较复杂模型。状态至少覆盖方向、波动、流动性和广度，避免把“上涨但缩量窄广度”压成单一牛市标签。

出站契约示例：

```json
{"as_of":"...","scope":"market|industry","horizon":"5d",
 "state_probs":{"risk_on_broad":0.31,"risk_on_narrow":0.42,
 "transition":0.20,"risk_off":0.07},"model_version":"...",
 "data_snapshot":"...","uncertainty":"high"}
```

证伪：概率长期失校准、状态不比朴素历史频率更能区分未来分布，或换一个合理行业分类便完全翻转，则状态层主张失败。

#### L4 事件研究与暴露层

职责：从权威来源建立事件台账；用公布前预期与实际值估算意外度；把行业暴露规则与实际价格反应分别输出；对重叠事件标注污染。

事件对象至少含：`event_id/type/scope/published_at/available_at/source_tier/fact/surprise/sign_uncertainty/exposure_vector/windows/confounders`。

方法以事件研究为基线：固定事前定义估计窗和事件窗，计算相对基准/行业的异常收益与成交变化；重大重叠事件不强行分摊唯一贡献。

证伪：安慰剂日期产生同等冲击、事件前已有完整价格反应、暴露映射跨样本不稳定，或剔除重叠事件后效应消失，则降低/撤销事件主张。

#### L5 个股价格事件预测层

职责：生成候选价格带，估计触达、受阻、有效突破、沉底联合事件的条件概率/分位数；状态和事件仅作为条件变量，不替代个股微观约束。

采用“两阶段”结构：

1. 候选生成器从可解释数据产生少量价格带：历史成交密集区、近期摆动极值、跳空边界、波动尺度分位数、合理的整数价聚类等。
2. 统计验证器估计在给定状态/事件/行业/个股特征下，各候选带对应事件的概率，并进行校准。

这比直接回归一个价点更符合“是否触达—触达后怎样”的事件结构，也便于辨别候选生成能力与概率排序能力。

证伪：候选带对未来极值的覆盖不优于等距/ATR 朴素带，验证器不优于无条件命中率，或概率无法校准，则退回朴素基线。

#### L6 评估、监控与发布层

职责：走步回测、概率校准、分组稳定性、模型登记、漂移监控、报告渲染与审计。

发布必须同时生成 JSON/Parquet 和 Markdown。报告里的每个数值须能反查机器结果，文字不得改变概率含义。

证伪：同一快照不能重现报告、模板能把低置信结论写成确定句、上线后校准持续越界而不触发降级，则发布层失败。

## 3. 三类价位的定义域与判据

### 3.1 公共定义域

对证券 `i`、截至时点 `t`、未来交易日时窗 `H`：

- 使用调整口径明确的 OHLCV；用于实际交易约束时同时保留未复权价格。
- 价格带 `B=[L,U]`，中心 `m`，宽度 `w=(U-L)/2`。宽度应随波动和最小价位变化，禁止全市场固定百分比。
- 信息集 `X_t` 仅包含 `available_time <= t` 的市场状态、事件、行业和个股特征。
- 所有阈值（触达、离开、保持、回撤、修复）在训练前固定，由 P0 标签研究冻结；不能逐例人工调整。
- 涨跌停、停牌、除权、上市初期等单独进入可用域或删失标记。

模型输出的是 `P(event within H | X_t, B)` 或条件分位数，不是自然法则。

### 3.2 压力位（resistance zone）

**定义**：位于参考价上方的价格带 `B`。若价格自下方首次触达 `B` 后，在反应窗 `R<=H` 内未能有效离带向上，且先发生规定幅度的回撤/相对弱化，则记为“受阻”。压力位预测是：

`P(touch(B) within H) × P(reject within R | touch, X_t)`，两项必须分开报告。

**判据主张**：候选带只有同时满足“可达性”和“触达后受阻概率有增量”才可发布。至少报告：带宽、触达概率、条件受阻概率、预计触达时间/期限、样本支持数、与朴素基线之差。

**理论依据**：限价订单与历史持仓/参考点可使供给在某些区域聚集；价格聚类和既有支撑阻力研究提示局部可预测性。但市场微观结构只支持“区域与概率”，不支持永恒精确线。

**怎么证明它错了**：

- 触达后的受阻率不高于相同距离的随机/等距价格带；
- 控制波动、趋势、成交和多重检验后增量消失；
- 样本外带宽稍变，结论即反转；
- 发布概率严重失校准，或净交易约束下没有任何增量信息。

### 3.3 突破位（confirmed breakout zone）

**定义**：突破不是独立画出的另一条神秘线，而是候选压力带 `B` 的上边界附近形成的**确认区域**。首次越过 `U` 后，须在确认窗 `C` 满足预注册条件，例如：收盘在 `U` 上方超过波动缓冲、连续保持 `k` 个观测或回踩未重新有效跌入带内，并在后续评价窗产生正向条件超额收益/不先触发失败回撤。

发布两种概率：

- `P(cross B within H | X_t)`：穿越概率；
- `P(valid breakout | cross, X_t)`：穿越后有效概率。

成交扩张、市场广度和行业共振可作为预测特征，不应被写成跨市场永真硬阈值。

**理论依据**：突破是首次通过与后续保持/收益的序列事件，适合离散时间风险模型、竞争风险或生存分析；将“盘中越线”和“有效突破”分离可减少事后挑选。

**怎么证明它错了**：

- 确认规则不比简单收盘越线提高后续条件收益或降低假突破率；
- 加入成交/广度后样本外无增益；
- 确认延迟吞噬全部信息价值；
- 在不同波动阶段、流动性组或交易板块中无法校准。

### 3.4 沉底价（bottoming-price zone）

**定义**：沉底是联合事件而非未来最低价的同义词。设未来窗内最低点为 `τ*`、价格为 `P*`。只有在 `τ*` 后的确认窗内同时满足预注册的稳定/修复条件（如不再创显著新低、从极值修复一定波动尺度、下行风险或相对弱势收敛），才把 `P*` 计为沉底价样本；否则是删失或“未沉底”。输出 `P(bottoming within H | X_t)` 以及在事件成立条件下 `P*` 的分位数区间。

因此推荐格式是：`沉底事件概率 34%；若在 10 日内形成，价格带条件中位数 [a,b]；截至 H 尚未形成概率 66%`，而不是“底价=a”。

**理论依据**：底部只有依靠未来路径才能定义，天然涉及路径依赖、删失和竞争事件；生存/风险模型结合条件分位数或分布预测比最小二乘点预测更合适。

**怎么证明它错了**：

- 条件区间覆盖率不达标或区间宽到无决策价值；
- “稳定/修复”条件对小幅阈值变化极端敏感；
- 模型无法优于近期低点、波动带或历史条件分位数；
- 把尚未完成确认的样本错误标底后，回测优势消失。

### 3.5 三者的关系与互斥边界

- 压力是“触达后的拒绝风险”；突破是“穿越后的保持/正向路径”；二者是同一候选带的竞争结果，可用竞争风险建模。
- 沉底针对下行极值后的确认，不应简单定义为“支撑位”。支撑触达后的反弹概率可以另建对象，但不能与完整沉底事件混名。
- 同一证券可在不同期限拥有不同价格带；跨期限不应覆盖成一个数字。

### 3.6 最小发布结构

```json
{
  "instrument_id":"...", "as_of":"...", "horizon":"10d",
  "price_basis":"forward_adjusted", "data_snapshot":"...",
  "market_state_probs":{}, "industry_state_probs":{}, "event_ids":[],
  "resistance":[{"band":[0,0],"p_touch":0,"p_reject_given_touch":0}],
  "breakout":[{"band":[0,0],"p_cross":0,"p_valid_given_cross":0}],
  "bottom":{"p_event":0,"conditional_band":[0,0],"no_event_prob":0},
  "calibration_version":"...", "support_n":0,
  "invalidators":[], "quality_flags":[], "model_version":"..."
}
```

## 4. 训练、评估与证伪纪律

### 4.1 回测协议

1. 严格按时间滚动/扩展窗训练，测试期永不参与阈值与特征选择。
2. 指数成分、行业分类、宏观修订值按当时版本重放；处理退市股，防止幸存者偏差。
3. 先冻结标签，再比较模型；标签定义和模型超参不得在同一测试集反复调优。
4. 基线至少包括：历史频率、近期高低点、波动/ATR 带、行业无条件模型。
5. 概率指标：Brier/log loss、可靠性图、ECE；排序指标：PR-AUC/ROC-AUC（类别不平衡优先 PR）；区间指标：覆盖率、宽度、pinball loss。
6. 路径指标：触达率、条件受阻率、假突破率、确认后超额收益分布、沉底事件覆盖和时间误差。
7. 按年份、波动状态、行业、流动性、涨跌停制度、上市年龄分组；报告最差组而非只报均值。
8. 若用于经济价值评估，纳入费用、滑点、不可成交、涨跌停和延迟；但统计预测质量与策略盈亏分开报告。

### 4.2 多重检验与研究治理

- 先登记假设、指标、阈值和测试期；所有试验进入实验台账。
- 候选规则多时使用假发现率控制、现实检验/自助法或严格留出集；禁止只展示赢家。
- 重大版本必须有 champion/challenger、模型卡、数据卡及一键回放。
- 连续两个监控窗校准越界时降级为基线或“不发布”；数据质量红线则立即阻断。

### 4.3 系统级反证

若发生任一情形，应否定或缩小系统主张，而不是换措辞掩盖：

- 三类价位在严格样本外均不优于朴素基线；
- 事件信息加入后没有稳定增量，或只有事后文本才有效；
- 行业状态概率不校准，不能改善个股条件分布；
- 结果主要来自未来函数、幸存者偏差、修订值或重叠样本；
- 在合理交易制度/成本约束下预测对象不可实现；
- 预测区间为了覆盖而宽到失去用途。

降级顺序：复杂模型 → 透明统计模型 → 分组历史频率/波动带 → 只报事实与“不足以预测”。

## 5. 面向执行侧的接口约定

### 5.1 硬约束（不得偏离）

| 编号 | 硬约束 |
|---|---|
| H1 | 禁读、禁引用既有正典策略与 ANALYZE.1/2；允许的内部材料仅是指定 15 份报告且只用于输出槽位分析。 |
| H2 | 全链路 point-in-time；每条数据同时保存事件时间、首次可得时间、采集时间、来源和修订版本。 |
| H3 | 市场、事件、行业三证据流并行，事件事实、暴露假设、价格反应和因果结论必须分列。 |
| H4 | 核心事件仅宏观/行业级；个股事件只做个股控制与风险标记。 |
| H5 | 压力、突破、沉底按本文事件定义标注，输出区间、期限、概率、失效条件；禁止单点确定性价位。 |
| H6 | 穿越与有效突破分开；未来极值与已确认沉底分开；未确认样本必须正确删失。 |
| H7 | 数值预测不得由大模型自由生成；LLM 产物必须保留来源证据并经结构校验。 |
| H8 | 必须采用时间外样本走步评估，与朴素基线比较，并报告概率校准、区间覆盖和最差分组。 |
| H9 | 复权、涨跌停、停牌、公司行为、退市和行业成员历史必须显式处理。 |
| H10 | 机器可读结果为事实源，人类报告只渲染；任何数字可追溯到快照、代码和模型版本。 |
| H11 | 数据质量失败、校准越界或证据不足时，系统必须降级/不发布，不能用文字补全。 |
| H12 | 任何新增主张都要附预注册的失败判据和可复现实验。 |

### 5.2 建议（执行侧可裁量，但须记录理由）

| 编号 | 建议 |
|---|---|
| A1 | 日频 MVP 先行，基准期限从 1/3/5/10/20 日中经标签研究选择。 |
| A2 | 状态层先做透明规则/逻辑模型，再挑战 HMM、变点或集成模型。 |
| A3 | 价带宽度采用波动尺度与最小价位联合规则；候选来自成交密集、摆动极值、缺口和价格聚类。 |
| A4 | 用离散时间风险/竞争风险建模触达—拒绝/突破，用风险模型+条件分位数建模沉底。 |
| A5 | 概率校准优先比较 isotonic、Platt/beta calibration；小样本避免过度分箱。 |
| A6 | 事件源优先官方/交易所/公司原文，其次权威通讯社；社交媒体仅作为线索。 |
| A7 | 报告保留“市场仪表盘—核心事件—行业分化—个股价带—下一窗口证伪—来源”槽位。 |
| A8 | 行业分类可比较申万/中信等，但必须版本化且保留历史成员。 |

偏离建议无需审批，但交付中必须写清选择、替代方案、证据和影响；偏离硬约束必须退回顶层评审。

## 6. 主张—反证总表

| 主张 | 可观测预期 | 否决条件 |
|---|---|---|
| 概率状态优于单标签 | 校准后概率可区分未来风险/收益分布 | 不优于历史频率，且跨期不稳定 |
| 三流并行有增量 | 合并模型严格样本外优于任一单流基线 | 增量在留出期消失或仅来自泄漏 |
| 事件须拆事实/意外/暴露/反应 | 安慰剂弱、事件窗效应与暴露方向可复现 | 安慰剂同强或重叠事件解释全部结果 |
| 价位应为区间 | 合理覆盖下区间较点预测稳定 | 区间过宽或覆盖仍不足 |
| 压力是条件受阻事件 | 触达后受阻率高于匹配带 | 控制距离/波动后无差异 |
| 突破须经路径确认 | 假突破减少且条件结果改善 | 延迟成本抵消全部增益 |
| 沉底须极值+稳定/修复 | 已确认底比单纯新低具有更稳定后续分布 | 阈值稍变即崩溃或覆盖不达标 |
| LLM 不负责数值预测 | 结构抽取提高覆盖且不破坏可追溯性 | 幻觉/漏引超过门槛或无法复核 |
