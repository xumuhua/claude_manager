**建行要点**：风险以「月」为单位积累（黄金是「日」），且泄压是**分段式**（涨一段泄 2-3% 再涨）——单日跌幅上限只有 -3.7%，永远不会有黄金式的 -10% 跳空。若用黄金的阈值套建行，会全年喊狼来了（原型实测见 §2.4）。

### 1.4 跨资产规律总结（风险评估值的定义约束）

1. **积累速度差 30 倍**：黄金 7 天攒满 vs 建行 8 个月攒满——绝对涨幅阈值不可跨资产，必须波动率标准化。
2. **释放形态三态**：跳空泄（黄金）/ 阴跌泄（纳指 2-3月）/ 分段泄（建行）——泄放通道须兼容三种。
3. **「完全释放」的共同度量**：du 回到 0–5% 区 + 距峰回撤到年度极值附近。这是三资产唯一可统一的低风险判据。
4. **低风险≠见底时间**：黄金 10 月低风险后惯性阴跌一个月；纳指 4 月低风险后立即 V 起。**低风险区的正确用法=蹲守（左侧建仓试探），不是预测翻转日**——与哥哥「惯性下跌没关系，蹲守动量翻转」完全一致。
5. **反例必须记录**：纳指 8 月高积累未释放（高位钝化）、建行 8 月释放被秒买回——风险值要允许「高位钝化」与「假释放」两种状态存续，不可硬编码「积累必释放」。

## §2 第二部分：RISK-4F 架构设计

### 2.1 设计哲学

把哥哥的描述翻译成机械语言——这是一个**弹簧能量账户**：

- 上涨 → 蓄能（风险+），速率由动能（ret5 波动标准化）与位置（du 势能）共同决定；
- 积累超过阈值 → 系统进入易释放态（暴跌/急跌概率抬升，但**不保证**释放——纳指 8 月反例）；
- 下跌 → 泄能（风险-），泄放速率>积累速率（不对称，暴跌两日泄掉半年积累是常态）；
- **完全泄放**（du 回 0-5% + 势能耗尽）→ 低风险态，此后惯性下跌不管、只蹲守动量翻转信号；
- 状态轮（1/2/3/4）做**调制器**而非独立输入——同一根阳线，状态1（健康上攻）与状态2（上攻尾声）的蓄能含义不同。

### 2.2 三通道架构

```
RISK_t = clip( POS_t + MOM_t + ST_t , 0, 100 )

【通道一：位置势能 POS】（慢变量，定"势"）
  du_t = ln(close/trough_t) / (σ20_t × k_pos)     # 距谷涨幅，波动标准化
  POS_t = min(du_t, 55)                            # 封顶防慢牛无界增长
  # 暴跌时 trough 更新→du 自动压缩 = 势能自动泄放
  # 建行解：du/σ 标准化后 +42% 慢牛势能与黄金 +21% 急涨势能可比

【通道二：动能蓄泄 MOM】（快变量，定"势的变化速度"）
  z_t = ret1_t / σ20_t                             # 单日波动标准化
  m5_t = ret5_t / (σ20_t × √5)                     # 5日波动标准化
  蓄能：z>0 且 m5>0 → MOM += α_up × min(z,3) × (1+β×max(m5,0))
  泄能：z<0 → MOM += α_dn × z × (1 + λ×1[m5<-1])   # 急跌日加速泄
  α_dn/α_up ≈ 2~3（不对称：泄得比蓄快）
  MOM 衰减：每日 ×0.98（动能热度自然冷却）

【通道三：状态调制 ST】（语义层，定"同样的价格变化该怎么解读"）
  状态1（健康上攻）：蓄能速率 ×1.2（涨得健康也在攒势能）
  状态2（上攻尾声）：蓄能速率 ×1.5（同样的涨，尾声更危险）
  状态3（下跌回撤）：泄能速率 ×1.6
  状态4（下压出清）：RISK 硬贴地 ≤12（框架级"完全释放"确认灯）
```

三资产**同一套参数**（α/β/λ/k_pos 网格标定一次通用），这是 OB-TP3 的教训直接继承：波动率标准化能跨资产，行情形态自适应交给状态调制通道，不在阈值上逐资产打补丁。

### 2.3 风险分区语义（对齐哥哥的原话）

| 区 | 读数 | 含义 | 操作含义（建议，非决策） |
|---|---|---|---|
| 低风险（蹲守区） | RISK≤25 且 du<5% | 风险完全释放 | 不再砍仓；启动动量翻转蹲守（probe 试探） |
| 惯性下跌段 | 低风险区内 RSI 未回 50 | 哥哥说的"没关系"段 | 空仓/轻仓等翻转信号，不接飞刀也不追空 |
| 中风险 | 25<RISK<65 | 积累或释放途中 | 预算层正常运作 |
| 高风险（易释放态） | RISK≥65 | 积累超阈值，暴跌概率抬升 | 止盈闸待命（TP-FINAL 的满仓前提天然衔接）、减仓 |
| 高位钝化（特设出口） | RISK≥65 且连续 20 日未释放 | 纳指 8-9 月形态 | 不硬等暴跌，按钝化衰减规则缓慢泄 RISK |

**「完全释放」的双门**（防假释放，建行 8 月教训）：RISK 进低区**且** du<5% **且**（状态4 出现 或 距峰回撤≥15%）——三条件同时满足才算完全释放，单一条件（如仅 RISK 低）只算"中低风险"。

### 2.4 原型实测与教训（v0，手工参数，仅验形状）

本报告随附一版手工参数原型（位置 0.10 权重+动能不对称+状态调制），三资产跑完暴露两个校准问题，如实记录：

1. **黄金 1/29 只到中风险上沿**——动能通道 cap=3.0 把 +15.2% ret5 的蓄能截断了（急涨尾部欠表达）；
2. **建行全年低风险**——0.985 日衰减把慢牛两个月攒的势能磨光了（衰减率与慢牛积累速率不匹配）。

**结论：手工拍参数不可行，必须网格标定**。标定空间：α_up∈{2,3,4}、α_dn/α_up∈{2,2.5,3}、k_pos∈{8,10,12}、衰减∈{0.98,0.99,1.00}、状态调制系数∈{±20%}，共 ~200 组合，目标函数=三资产分区与 §1 事后标注的重合率最大化（见 §3 验收）。

### 2.5 与现有体系的衔接（不重造轮子）

| 现有部件 | RISK-4F 接入点 |
|---|---|
| 状态轮（1-4） | 通道三直接消费状态码，零改动 |
| 预算层 w_total | RISK 高区→建议 w 上限下移（调制而非替换，预算层继续管状态） |
| TP-FINAL 止盈闸 | 高风险区=止盈闸的"满仓前提"之外再加一盏预警灯（非硬触发） |
| SL 3%/5% 止损闸 | 互不干扰（止损管急跌当下，RISK 管积累-释放周期） |
| 低风险蹲守 | 对接状态4 的 probe 机制（半仓试探翻转），RISK 贴地=蹲守许可 |

### 2.6 防过拟合边界（写死）

1. 单窗单 regime：三资产各一段行情，标定参数是样本内拟合，**跨窗复验（2025 窗）是采纳前置条件**；
2. 「积累必释放」不成立（纳指 8 月反例），架构保留高位钝化出口，不硬编码因果；
3. 验收用重合率+前瞻收益，不用样本内收益（避免把风险值调成收益预测器）；
4. 全部参数扫描结果全报，禁挑峰值（OB-TP2 悬崖教训）。
