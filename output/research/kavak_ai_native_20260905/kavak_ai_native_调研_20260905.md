# Kavak AI-Native 转型调研

> 哥哥 9/5 令：调研 Kavak（拉美二手车平台）的 AI native 化，"据说这家公司做的很彻底"
> 来源：a16z 播客（8/10，36 分钟）+ 华尔街见闻 AI原生Lab 全文拆解
> 链接：https://wallstreetcn.com/articles/3779164 ；https://a16z.com/podcast/from-copilots-to-agents-rebuilding-the-company-around-ai/

## 一、公司底子

拉美最大二手车平台、墨西哥首家独角兽（估值曾 80 亿美元）。业务：买车-翻新-卖车-车贷。拉美缺成熟的汽车交易基础设施，Kavak 被迫把检验/物流/金融/保险全部垂直自建——没有一个环节外包，所有数据都在自己手里。这是它敢 All-in AI 的本钱。

受访者：Alejandro Maza Ayala（首席产品与AI官，2013 年起做机器学习），与创始人 Carlos Garcia Ottati 共同推动三年转型。

## 二、三个赌注（转型顶层设计）

1. **围绕 AI 重新设计整个公司**（不是"采用"AI）。Alejandro 反复纠正"采用"这个词：把 AI 嵌入旧流程只得 6% 改进，让 AI 重新定义流程才有 10 倍。做法是反向推：先想清楚 2035 年的 Kavak 长什么样，从现在开始建那个版本——组织结构、团队配置、工作方式全部重设。
2. **造超人类 Agent**。在他关心的每个维度上，Agent 表现都超过雇过的最好员工。关键的学习机制：一个 Agent 犯错学到，次日全系统 20 万个 Agent 全体同步学到。无穷耐心+全部历史记忆+长期规划+不累。
3. **换 KPI：交易型→关系型**。以前盯买了多少车卖了多少车；现在数据库里一千万客户，每人配一个 Agent，唯一目标=最大化客户终身价值。激活 1% 客户基数=几亿美元增量收入。二手车核心是信任，信任靠了解客户、经营长期关系。

三个赌注全部押对的结果：**96% 客户交互、95% 交易由 Agent 完成；每天按需启动 10-20 万个专属 Agent**（各跑独立虚拟机）；销售转化率=人类最好团队的 2.1 倍（上线初期就 +50%）；NPS×3；车贷审批 2 个月→3 分钟。

## 三、架构反转：Agent-per-task → Agent-per-customer

Kavak 一开始也做 Multi-Agent 图（客户→销售 Agent→贷款 Agent→保险 Agent→交易 Agent），后来推翻：为什么按"任务"拆 Agent？模型足够聪明时，一个 Agent 可以走完整个客户生命周期。

**新架构**：客户进入系统 → 生成专属 Agent + 分配一台独立虚拟机 + 完整记忆（两年前的电话/浏览/聊天/贷款申请都在同一上下文）+ 一个长期目标（最大化该客户终身价值）。Agent 不急于推成交：看车阶段推车型+融资方案、有旧车主动提置换、贷款困难调方案、没买也持续跟踪，几个月后合适时机再激活。

架构极简：**每客户一台虚拟机、一个 Agent、一套记忆、一套评估、一个长期目标**，Agent 调用公司所有 API 工具，像全能员工服务这一个客户。模型变强后，复杂结构反而在限制智能。

**车贷审批 3 分钟的由来**：卖二手车要在约 2 万种车型里选，还要处理融资/保险/旧车置换，成交周期 3-4 个月。过去 15 个领域专家团队接力（客户不断被转手），Kavak 把 15 个团队的专业能力整合进一个"超级专家" Agent 直接面对客户。

## 四、评估投入 = 建 Agent 投入

Alejandro 的经验法则：花在评估上的工程师时间/Token/资金，与建 Agent 本身大致 1:1。评估不是上线后的质检，是与开发同等重要的基础设施——评估做得越好，才敢放 Agent 进真实业务。"企业 AI 的刹车不在模型安全，在评估质量。"

只测业务结果，不测表面 KPI（通话时长/对话轮次）也不测基准分：客户最终买车了吗？贷款批了吗？车卖给我们了吗？还会回来吗？

## 五、AI CEO 实验（库埃纳瓦卡全城）

把一座城市的业务交给一个 AI Agent 当 CEO：不是分析经营数据，而是像极度精细的管理者——每天给销售/检验员/一线员工发工作计划，员工语音反馈进展，AI 持续评估调整。库存管理/库存周转/融资渗透率/客户满意度全在管辖内。

第一个月目标利润翻倍，实际做到 **1.5 倍（+50%）**，几乎所有核心指标改善。团队决定实验继续。Alejandro 判断：按当前 AI 进步速度，2035 年 CEO 这类工作也能由 AI 完成。

## 六、物理世界：AI 副驾驶"El Mike"

墨西哥约 800 名机械师不替代——车辆检测/维修/翻新涉及大量精细肢体操作和感官判断。做法=AI 副驾驶 El Mike（用《料理鼠王》比喻：AI 是厨师帽里的小老鼠，背后指导人类）：AI 负责知识和判断，人负责物理执行。结果：检测维修更快更省，翻新质量提高，质保指标改善。

## 七、全员改造："绝地武士学院" + 组织压扁

- 内部培训六周，CEO 到机械师全员参加，每人从零训一个 Agent 上生产。Alejandro："可以学、跟上这个新现实，也可以选择离开。"
- 课程自己设计且不停更新——"你不能把人送到斯坦福学这个，没人教过。"
- 组织结构剧变：管理层级压极扁，一个团队里工程技术/AI/运营/一线共存——所有人要么在建 Agent，要么帮 Agent 工作，要么在物理世界面对客户。
- Agent 搞不定的事通过 API 呼叫人类（"我需要帮助"），人做完 Agent 记下来学会——**每次人工介入都变成 Agent 训练数据**。

## 八、推进方式与度量：自上而下 + Token 三层记账

- **必须自上而下**：一线员工不可能自下而上定义公司级 AI 战略。领导者要有清晰图景（3-5 年后公司长什么样），垂直拉动全员。
- **Token 分三层**：
  - 第三层（最有价值）：可直追 ROI 的 Agent——每花一个 Token 知道带来多少业务价值
  - 第二层：间接可衡量（结果变化可评）
  - 第一层（最难衡量）：员工日常用 Claude Code/ChatGPT 的 Token——企业往往不知道产生了什么价值
- 核心问题不是"AI 有没有被采用"，而是"每花一个 Token，它给公司带来了什么收益"。

## 九、最触动的一条：福特工厂的教训（创造性破坏）

福特流水线需要的所有技术在 1879-1881 年就全有了（爱迪生商业化电力+高效发电机）——1881 年技术上就能建福特工厂。当时的人怎么"采用"电力？把蒸汽机换成电动机，工厂还是四层楼，皮带传动轴一样不少——效率只提升约 6%。**真正要做的：推倒那栋楼，在平地上建单层工厂，围绕小型发电机重新设计整条产线**——效率提升 3 倍，驱动了美国整个 20 世纪的生产力。

"同样的故事今天正在重演。人们想'采用' AI，但不愿意彻底重新设计公司。只做表面采用，给你 6% 或 10% 的改进，不会给你 10 倍。"

## 十、可借鉴的三条硬经验（AI原生Lab 总结）

1. **从上往下，从图往点**：自上而下推进+领导者想清终局；技术架构同理——从多 Agent 图切到每客户一个 Agent 的极简架构，模型变强后复杂结构限制智能。企业选择：让现有组织定义 AI 用法，还是让 AI 能力定义未来组织。
2. **评估和建设同等投入**：先搭评估再放 Agent 跑；评估越扎实，Agent 越能跑进核心流程。
3. **围绕 AI 设计公司，而非"采用"AI**：6% vs 10 倍的分界线。
