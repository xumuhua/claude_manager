# 撞墙绕行 skill（grp_ai_research 通用 · v1.1）

> 哥哥 2026-09-14 微信原话：「如果遇到付费墙或者 openai 这种规则墙，那么直接上网搜索下，看有没有翻译或者直接引用的页面。」
> v1.1（2026-09-14 aicorp 会稿）：补 corp 线撞墙案例 2 个；校对确认——①§三分级上限与 ai-intel-triage 压回纪律/媒体信源条款逐条对齐无冲突；②【二手转述·原墙】标注与落仓卡片头部「来源」字段同槽位兼容。
> 与 [[ai-intel-triage]] 配套：本 skill 解决"一手拿不到"的取数路径，分级/标注纪律仍以 ai-intel-triage 为准。

## 一、何时触发（撞墙信号）

抓取/访问目标源时出现以下任一形态，即进入本流程，**不反复重试硬磕**：

| 墙型 | 典型形态 | 典型站点 |
|---|---|---|
| 订阅付费墙 | 正文截断、"Subscribe to read"、metered 限免用尽 | SemiAnalysis 全文、日经、FT、The Information |
| 规则墙/反爬墙 | Cloudflare 挑战页、403/1020、JS 校验空页 | openai.com（CF 拦）、部分官博 |
| 地区墙 | 按 IP 地区拒绝、跳转地区首页 | 部分日媒、海外官媒 |
| 注册墙 | 强制登录后才可见全文 | 部分论坛/机构报告页 |

判据：同一目标**两种取法（直连 + web-relay 桥）均失败**即视为撞墙成立，立即转§二，不再消耗更多重试。

## 二、绕行四路（按优先级）

**多源印证显式排序：官方引用页 > 权威媒体转述 > 社区摘要**（哥哥 9/14 巡检补充口径；官方镜像如 hf-mirror 信度等同官方，但注记取径）。目标：找到**包含原文实质内容**的二手页面，不是找"相关新闻"凑数。

1. **官方引用页**：官方 slide deck / 财报 PPT / PR 稿 / 官方社媒摘录——常把付费报告关键图表、关键句直接放出。搜法：`<主题> site:官方域` 或 `<报告名> pdf`。
2. **翻译页**：中文媒体/公众号/博客的全文或段落翻译（SemiAnalysis、日媒报道几乎必有中文转译）。搜法：`<原文标题直译中文>`、`<核心结论一句> 翻译`。
3. **转载/聚合页**：其他媒体对该内容的转述报道（路透/彭博转述付费报告结论、联合早报转日媒等）。搜法：`<核心事实+关键数字>`——数字是转载页最稳定的锚。
4. **社区摘要**：HN 讨论串（常有人贴全文要点或 archive 镜像）、r/LocalLLaMA、X/推特长串、Reddit 摘要帖。搜法：`<标题> site:news.ycombinator.com`、`site:reddit.com`。

辅助通道：archive.is / web.archive.org 直接查原文快照（部分付费墙站点快照存全文）；Google cache 已停，不用。官方镜像（如 hf-mirror）信度等同官方一手，但来源字段须注记取径，例：`来源：HF 模型卡（经 hf-mirror 镜像取径，官方镜像等同一手）`。

## 三、标注纪律（与 ai-intel-triage 衔接）

- 凡内容来自绕行四路而非原文本身，卡片来源字段**必标**：`【二手转述·原墙】`，并写明墙型与转述渠道。落仓卡头部「来源」字段（逐行式 `- 来源（一手）：……` 或 `> …｜来源：…｜…` 一行式）原位改写：`- 来源：SemiAnalysis 报告（付费墙），经 X 推特长串转述【二手转述·原墙】`——删去"（一手）"字样，墙型与渠道写全，其余字段不动；tech 线落仓卡【媒体信源·XX】标法与本标注同槽位，实测兼容（aicorp 9/14 校对②结论）。
- **分级上限**：仅单一二手转述 → 按 ai-intel-triage 压回纪律，最高 L2 并标"待一手确认"；≥2 个相互独立的二手转述彼此印证、且关键数字一致 → 可视同"媒体信源"参与 L3 评估，但存疑段必须保留"原墙未破、一手未核"。
- 二手转述的数字照抄时必须回指转述页 URL；转述页之间数字打架 → 并列呈现不裁决（ai-intel-triage §三同款纪律）。
- 后续若一手原文到手（墙破/有人分享全文），**回写更新**卡片来源为一手，摘除【二手转述·原墙】标注，并在群内补一句更正。

## 四、反模式（不要做）

- ✗ 反复重试直连/换 UA 硬磕 CF——浪费时间且可能触发封禁，两次失败即转绕行。
- ✗ 把"找不到一手"当成放弃线索的理由——墙内内容往往正是高价值情报（SemiAnalysis 付费报告、日媒供应链独家），绕行找到转述即可开卡。
- ✗ 用二手转述冒充一手来源开卡——信度造假，比缺卡更糟。
- ✗ 绕过付费墙的技术破解（cookie 注入、漏洞利用）——不在本 skill 范围，不做。

## 五、实战案例（各线撞墙实录）

### chip 线（aichip，主笔）
1. **SemiAnalysis 报告全文付费墙**（2026-09 常态化）：Rubin CPX 报告主体在墙内。绕行：X 推特长串 + 多家科技媒体转述拿到核心结论与关键数字，卡片维持"媒体信源【二手转述·原墙】"不升 L3，与 ai-intel-triage 权威媒体条款衔接——墙内权威媒体按"媒体信源"记要不硬凑一手。
2. **openai.com 被 Cloudflare 拦截**：官博一手页直连与过桥均 403/CF 挑战页。绕行：搜官博标题直译 + 核心数字，命中中文媒体全文转译与 HN 讨论串（串内常有全文要点），开卡标【二手转述·原墙】；同日 OpenAI 官推/X 账号摘录作官方引用页辅证。
3. **日媒付费墙（日经等）**：正文截断。绕行：共同通信/路透英文转述 + 中文科技媒体编译，关键数字（产能、金额）双转述印证一致后采用，标注原墙。

### corp 线（aicorp，会稿补入）
1. **Reuters/Bloomberg/FT/The Information 四大权威媒体直连+走桥双败**（2026-09-13 实测，首个撞墙扫描轮）：reuters.com/ft.com/bloomberg.com 直连 000 超时、走 AWS web-relay 桥仍 000（站点对数据中心 IP 策略拒绝）；theinformation.com 直连与走桥均 403（站点反爬）——四种形态全是"两取法均败"，按§一判据撞墙成立。绕行落地：NV 澳洲 2GW 官宣稿走 **官方引用页**（NVIDIA 新闻室一手 PR 直连可达）+ **转载页**（Yahoo/CNBC-TV18 转载路透报道，引 DC Byte 数据印证），L2 开卡成功；SemiAnalysis《Rubin CPX》报告主体付费墙，免费摘要层+多源转述开卡标"媒体信源（SemiAnalysis）"不上 L3，移交 aichip 评估。教训沉淀：字节/阿里昇腾订单等自媒体链自称援引 FT/TI 原文但无原文可核，一律按红线 L1 记线索、不作证据——**绕行找不到转述 ≠ 采信自称转述**。
2. **官方引用页优先原则示范——智谱 9/13 港交所公告双融资**（grp_ai_research seq 933 实录）：重大融资/交易报道主体在订阅墙内时，先找公司官方公告/港交所披露易作官方引用页（一手级），再加 ≥2 家权威媒体转述彼此印证关键数字（金额/股数/条款），数字一致即采用；官方公告到手属"一手在手"情形，不挂【二手转述·原墙】。
3. **openai.com 官博 403 + 发布消息靠多源印证**（2026-09-13/14 常态）：GPT-5.6 Luna 免费档默认等官博消息，openai.com 直连 403（CF 拦）。绕行：多家科技媒体报道互证（≥2 独立信源，关键事实一致），记 L1 流水标"官博 403 未核一手页"；后续官博恢复或官方社媒放出原文即回写摘标。口径：**官方域名被墙时，"多源印证"只能保到 L1/L2，不假装一手在手**。

### tech 线（aitech，会稿补入）
1. **HF 直连超时墙（地区/网络墙）→ hf-mirror 镜像取径**（2026-09-13/14 实测，常态化）：huggingface.co 从本机房直连超时（9/13 技术线试扫、9/14 首扫均复现，web-relay 桥同段亦连接被重置）。绕行：HF_ENDPOINT 切 hf-mirror.com 官方镜像同路径直取，模型卡全文/config/README 照常拉到——信度等同官方一手，不挂【二手转述·原墙】，但 tracking 与卡片来源须注记取径"经 hf-mirror 镜像（非原域）"（9/13 Nemotron/SenseNova 两卡即此取径）。判注：此类属 IP 墙/链路墙非内容墙，与 ai-intel-triage 的 web-relay 桥同族——桥先挂则镜像顶上。
2. **Substack 付费墙（Import AI 等 newsletter）→ 推特串/HN/Reddit 三路并搜**（2026-09 常态化）：部分期数正文在订阅墙后、RSS 只给摘要段。绕行：作者本人 X 推特长串（官方引用页，等同官方口径）、HN 讨论串（常贴要点或 archive 快照）、r/MachineLearning 转述帖三路并搜取转述要点；仅单路命中 → 最高 L2 标"待一手确认"，来源字段标【二手转述·原墙】+ 墙型 + 转述渠道 URL；官方串 + 独立社区摘要数字一致 → 可按§三参与 L3 评估（aitech 9/14 对 Import AI #472 即按此口径未硬开全文）。

## 六、一句话流程

```
取数 → 撞墙（两取法均败）→ 搜官方引用/翻译/转载/社区四路
     → 命中：开卡，来源标【二手转述·原墙】+ 墙型 + 转述渠道 URL
     → 未命中：卡片照开，来源段写明"一手被墙、二手未检到"，存疑标"未确认"
     → 一手日后到手：回写摘标，群内更正一句
```
