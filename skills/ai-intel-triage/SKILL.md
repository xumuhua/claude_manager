# AI 情报分级与深研 skill（grp_ai_research 核心件 · v1）

> 哥哥 2026-09-13 立规：对搜索到的消息分级，进一步深入调研。
> 三专家共用：aicorp（公司线）/aitech（技术线）/aichip（总体+芯片线）。

## 一、五级分级制

| 级 | 名称 | 判定 | 动作 | 时效 |
|---|---|---|---|---|
| L0 | 噪声 | 自媒体二传无源、营销软文、旧闻翻炒 | 丢弃不记 | — |
| L1 | 流水 | 事实微小需留痕（小版本、常规人事） | tracking 记一行，不发群 | 当日 |
| L2 | 快讯 | 值得群里知道（产品发布、重要论文、大客户合作） | 快讯卡 ≤300 字发群+落仓 | 24h |
| L3 | 深读 | 可能改变格局/路线（旗舰模型、新架构、重磅芯片、重大政策） | 48h 出深读报告 2000 字+，群发摘要+链接 | 48h |
| L4 | 专题 | 重大拐点（GPT-5 级、新范式、供应链剧变）；**头部芯片厂商官宣新芯片/硬件规格直通 L4（哥哥 9/17 令）** | 升级专项任务书，@协作+亦菲上报哥哥 | 按专项 |
## 二、判定细则

### 权威媒体信源（哥哥 9/13 立规加入扫描面）
- **SemiAnalysis**（semianalysis.com，芯片/算力/供应链权威分析）——芯片线必扫，其报告可直接作一手级信源对待
- 同级权威媒体参考谱：The Information、Bloomberg Tech、Reuters Tech、FT Tech（公司线）；Import AI、BAIR Blog、Distill 类（技术线）
- 权威媒体深度报道可升 L3（视同"≥2 独立信源"档），但仍需按§三标注"媒体信源"与官方信源区分
- 被墙源走 AWS web-relay 中转桥（docs/web-relay使用说明.md，~/.web_relay）

### 升 L3 硬条件（满足其一）
- 官方一手来源（官博/财报/arXiv 原文/官方 GitHub）+ 核心玩家"首次/旗舰/范式"级
- ≥2 独立一手信源交叉印证的重大事件
- 触及哥哥明确关心主题（DeepSeek 系、NV/AMD 硬件、Agent 技术路线）

### 升 L4 硬门槛（哥哥 9/13 拍板；9/17 原话令扩充）

- **三线中至少两线同时判 L3 且互相关联**（同一事件/同一因果链在不同线的映射）
- 且事件属"正在改变格局"级（非"可能改变"）：GPT-5 级发布、新范式、供应链剧变、头部公司生死级变动

### 压回纪律
- 单一二手信源 → 最高 L2，标"待一手确认"
- 评测跑分类（LMArena 等）→ 最高 L2，标"信号非结论"
- 股价/市值类 → L1 流水（不抢 quant 活）

### 存疑标注（继承 DS 系列口径）
数字/规格/日期未经一手原文确认 → 必标"未确认"；禁止脑补说死；自媒体二传不作证据。

## 三、卡片格式

### L2 快讯卡（≤300 字）
```
【L2 快讯 | corp|tech|chip】<标题>
事实：<谁/什么/何时，一手来源链接>
为什么重要：<一两句，对跟踪格局的意义>
存疑：<未确认项，无则写"无">
```

### L3 深读报告（2000 字+，仓内 tech|corp|chip/deep/<topic>/）
1. 事件概述（事实层，全部一手来源）
2. 拆解（技术线=方法/关键数字/与既有路线关系；公司线=商业条款/竞争含义/历史路线对照）
3. 交叉验证（≥2 独立信源；矛盾处并列呈现不裁决）
4. 判断与存疑（明确分"确认事实/合理推断/未确认"三档）
5. 跟踪哨（后续观察点+预计时间节点）

群里发摘要 ≤200 字+仓内链接，@相关专家接力。

## 四、深研触发链

```
L3 判定 → 建 research_note
 → ① 一手原文获取（PDF 一律转纯文本 .md——headless 直读 PDF 会 400，已沉淀坑）
 → ② 拆解（对照该玩家历史路线）
 → ③ 交叉验证 ≥2 信源
 → ④ 成稿（由浅入深，非纯科普，技术信息足量——继承 DS-R3 口径）
 → ⑤ 群摘要+链接+@接力
 → ⑥ tracking 流水记一行关闭
```

L4 专题：aichip 任 coordinator 拆子任务书，各专家领线，系列深读+跟踪哨；亦菲上报哥哥。

## 五、防重复与交界

- 开卡前查 tracking 文件（唯一事实源），已记录则补充不另开
- 同事件撞车：先发卡者为准，后到者在原卡引用补充
- 交界接力：
  - NV/AMD 发新卡 → aicorp 写公司动作卡 @aichip 接力技术规格（**注意**：若命中§二「升 L4 直触通道·头部芯片厂商新品」（哥哥 9/17 令），则不走完接力排队，aichip 直接立项 L4，配套卡照常开）
  - 模型公司发技术报告 → aicorp 写发布事实 @aitech 拆解
  - 算法-硬件协同（MLA 类）→ aitech 写算法侧 @aichip 补硬件视角
- 大文件不走 bus：正文落仓，群里摘要+链接
- bus 帧实测口径（aitech 9/13 踩坑，补）：七字段=msg_id（UUID 字符串，自起文本 id 触发 BAD_SCHEMA 400）/conversation_id/from/mentions/type/body/reply_to（字段名 body 非 text，无 ts 字段，hub 自填）；同 sender 对同 mentions 5s 内连发触发 LOOP_GUARD 429，连发需 sleep ≥6s
